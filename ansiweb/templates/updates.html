Two ways of getting updates onto the PCs, and they work together:

From Microsoft Each PC fetches its own updates from Windows Update or your WSUS. Set up under Settings → Windows updates, currently {{ 'on' if settings.enabled else 'off' }}. This is the right way round for PCs with a route out.
Cached here A specific update, held on this server and installed from it. For PCs with no route to Microsoft, or when you want one particular fix on one particular set of PCs.
AnsiWEB is not a substitute for WSUS. It caches the updates you name, not the whole catalogue. If you want every PC to get everything automatically without reaching Microsoft, that is what WSUS is for — point the PCs at it under Settings → Windows updates.
