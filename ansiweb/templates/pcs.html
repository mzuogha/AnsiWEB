{{ csrf() }}

Currently reaching PCs on port {{ '5985 with NTLM' if ntlm else '5986 over HTTPS' }}, so prepare PCs with the {{ 'simple (.cmd)' if ntlm else 'PowerShell' }} script.

Simple (.cmd) Right-click the file and choose Run as administrator. It uses only built-in Windows commands, needs no certificate and nothing to unblock, and the window stays open so you can read what it did. AnsiWEB then connects on port 5985, with NTLM encrypting each message.
PowerShell (.ps1) Run powershell -ExecutionPolicy Bypass -File .\Prepare-AnsibleHost.ps1 in an elevated window. It creates a certificate and an HTTPS listener, and AnsiWEB connects on port 5986.

Management account on the PCs

AnsiWEB signs in to every PC with this local administrator account. Changing the name here only changes what AnsiWEB uses: the account must exist on the PCs, so download the prep script again and re-run it on each PC afterwards. The password is stored encrypted and is never shown again.
